# Vehicle Event Detector

Detects vehicle-related acoustic events including crashes, horns, skids, engine
revving, and emergency sirens.

## Key discriminators

- **Crash**: broadband impulse, high peak energy, fast attack
- **Horn**: tonal/harmonic, 180–900 Hz fundamental, sustained
- **Skid**: narrowband friction noise 800–4500 Hz, medium duration
- **Engine rev**: low-fundamental harmonics 40–450 Hz, long duration
- **Siren**: FM-modulated tone, 0.4–4 Hz modulation rate
