# Product Roadmap (Item 136)

Organized around outcomes, not features.

## Now (v5.0)

### Make deployment commissioning self-service
- Deployment wizard with preflight checks
- Automatic node discovery and cell proposal
- One-click simulation for evaluation

### Make evidence independently verifiable
- Deterministic replay
- Exportable evidence bundles with checksums
- Cryptographic audit chain

### Make fleet maintenance proactive
- NodeCare predictive maintenance
- Automated calibration monitoring
- Service task workflow

## Next (v5.1)

### Make model improvement safe
- Shadow mode comparison dashboard
- Automated A/B evaluation gates
- Rollback without data loss

### Make integration seamless
- Webhook reliability (signed, retried, dead-letter)
- SDK for Python, TypeScript, Rust
- Plugin marketplace foundation

## Later (v6.0)

### Make scale invisible
- Horizontal scaling of correlation engine
- Multi-region deployment
- Federated model learning

### Make operations intelligent
- Automated deployment topology optimization
- Predictive network planning
- Anomaly-driven maintenance scheduling
