# Funding

## What Sponsorship Supports

Resonance is developed as an open-source project. Sponsorship directly funds the physical infrastructure and operational costs required to develop and validate a hardware acoustic sensing platform.

### Hardware Development
- **Prototype PCBs:** Dual-ring array boards, compute module carriers, power regulation boards. Each revision cycle costs materials, fabrication, and assembly.
- **Microphones:** MEMS microphone components for prototype arrays (16 per node, multiple test nodes).
- **Calibration equipment:** Reference microphones, anechoic measurement fixtures, timing validation hardware.
- **Enclosures:** Prototype enclosure fabrication (3D printing, CNC machining) for environmental testing.

### Testing and Validation
- **Field testing:** Travel, mounting hardware, and time for outdoor validation deployments.
- **Environmental chambers:** Access to temperature and humidity chambers for environmental specification validation.
- **Acoustic test datasets:** Licensed acoustic event recordings for ML training and validation.

### Infrastructure
- **Hosting:** CI/CD runners, documentation hosting, package registries.
- **Development tools:** PCB design software licenses, simulation tools.

## How to Sponsor

- **GitHub Sponsors:** Recurring monthly support at any level via the Sponsor button on the repository.
- **One-time contributions:** Via GitHub Sponsors one-time option.
- **Hardware donations:** Test equipment, development boards, and components. Contact the project maintainers.
- **Corporate sponsorship:** For organizations interested in supporting open acoustic safety infrastructure, contact the project via the repository discussions.

All sponsors are acknowledged in the repository (with permission). Sponsorship does not grant influence over technical decisions, roadmap priority, or privacy architecture.
