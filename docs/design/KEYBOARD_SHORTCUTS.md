# Keyboard Shortcuts (Items 112, 18)

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open command palette |
| `/` | Focus search |
| `G then L` | Go to Live view |
| `G then I` | Go to Incidents |
| `G then F` | Go to Fleet |
| `G then D` | Go to Deployments |
| `G then M` | Go to Models |
| `G then S` | Go to Settings |
| `Escape` | Close modal / dismiss |
| `?` | Show keyboard shortcuts |

## Incident Detail

| Shortcut | Action |
|----------|--------|
| `R` | Start review |
| `E` | Export evidence |
| `P` | Replay incident |
| `C` | Compare models |
| `N` | Add note |
| `[` / `]` | Previous / next incident |

## Fleet

| Shortcut | Action |
|----------|--------|
| `D` | Run diagnostics on selected node |
| `U` | Update firmware |
| `M` | Mark for maintenance |

## Data Tables

| Shortcut | Action |
|----------|--------|
| `J` / `K` | Move row selection down / up |
| `Enter` | Open selected row |
| `X` | Toggle row selection |
| `Ctrl+A` | Select all |
